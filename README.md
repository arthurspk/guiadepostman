## :dart: O guia para alavancar a sua carreira

> Postman é a ferramenta mais usada do mundo para testar, documentar e automatizar chamadas de API — do primeiro `GET` manual a pipelines inteiros de testes rodando em CI/CD. Ela nasceu como uma extensão simples do Chrome e hoje é uma plataforma completa: coleções organizadas por pastas, ambientes com variáveis, scripts de teste em JavaScript, mock servers, monitoramento agendado e, mais recentemente, um modo com IA que constrói e depura requisições a partir de comandos em linguagem natural. Este guia reúne documentação oficial, cursos, canais, ferramentas do ecossistema (Newman, Postman CLI, VS Code), projetos práticos, certificações e um capítulo específico sobre usar IA no dia a dia com Postman — tudo verificado, para quem está criando a primeira coleção ou já mantém suítes inteiras de testes de API.

## 🗺️ Roadmap

- [roadmap.sh — API Design Roadmap](https://roadmap.sh/api-design) — Roadmap visual e interativo da comunidade sobre design e boas práticas de API; a base conceitual do que você testa no Postman.
- [roadmap.sh — Backend Roadmap](https://roadmap.sh/backend) — Roadmap completo de back-end; mostra onde testes de API com Postman e Newman entram no fluxo de trabalho de um(a) desenvolvedor(a).

**Trilha resumida** (siga na ordem; cada etapa tem recursos nas seções abaixo):

1. **Fundamentos de API e HTTP** — métodos (`GET`, `POST`, `PUT`, `DELETE`), status codes, headers, JSON.
2. **Instale o Postman** e faça sua primeira requisição a uma API pública.
3. **Coleções e variáveis** — organize requisições em pastas, use ambientes (`{{baseUrl}}`) para não repetir valores.
4. **Autenticação** — API Key, Bearer Token, OAuth 2.0: como configurar em cada request.
5. **Scripts de teste** — escreva asserts em JavaScript (`pm.test`, `pm.expect`) para validar respostas automaticamente.
6. **Execução em lote** — Collection Runner e dados de teste (CSV/JSON) para rodar o mesmo teste com várias entradas.
7. **Automação em CI/CD** — Newman e Postman CLI para rodar coleções via linha de comando em pipelines.
8. **Mock servers e monitors** — simule respostas antes da API existir e monitore endpoints em produção.
9. **Especificações e Postman Flows** — importe/gere specs OpenAPI e explore automações visuais (inclusive com blocos de IA).
10. **IA na prática** — use o Agent Mode para gerar coleções, testes e depurar erros a partir de comandos em linguagem natural.

## 🤖 IA na prática

O Postman incorporou IA diretamente no fluxo de trabalho de quem testa APIs: em vez de escrever cada request e cada assert manualmente, você descreve o que quer em linguagem natural e o **Agent Mode** monta a requisição, os testes e até corrige erros.

**Para aprender**
- Leia a [visão geral de IA no Postman](https://learning.postman.com/docs/getting-started/basics/about-ai) para entender onde a IA aparece: geração de requests, de testes e o próprio Agent Mode.
- Ative o [Agent Mode](https://learning.postman.com/docs/use/agent-mode/overview) e peça, em uma coleção de estudo, para ele "criar uma requisição para a API do ViaCEP e um teste que verifique o status 200" — compare o resultado com o que você faria manualmente.
- Use os **Skills** do Agent Mode (comando `/` no chat) para automatizar tarefas repetitivas, como gerar um conjunto de testes de regressão para uma coleção existente.

**Para trabalhar**
- No dia a dia, use o Agent Mode para: depurar por que uma requisição está retornando erro, gerar documentação de uma coleção e sugerir casos de teste que você não pensou (respostas 4xx/5xx, campos ausentes, paginação).
- Configure [servidores MCP dentro do Postman](https://learning.postman.com/docs/use/send-requests/protocols/ai-requests/add-mcp-servers) para conectar o Agent Mode a ferramentas externas (bancos de dados, outras APIs) durante os testes.
- Explore os [blocos de IA no Postman Flows](https://learning.postman.com/flows/build-flows/ai/ai-request-blocks/overview) para montar automações visuais que chamam modelos de IA como parte de um fluxo de teste — por exemplo, validar semanticamente o conteúdo de uma resposta, não só o formato.
- Veja o [bloco AI Agent do Flows](https://learning.postman.com/flows/reference/blocks/ai-agent) para orquestrar chamadas de API guiadas por um agente dentro do próprio fluxo.

**Limites e boas práticas**
- A IA pode inventar campos, endpoints ou parâmetros que não existem na API real — sempre confira a resposta contra a documentação oficial do serviço que você está testando.
- Não cole tokens, chaves de API ou dados de produção em prompts sem revisar a política de segurança da sua empresa; o [FAQ de segurança e IA do Postman](https://learning.postman.com/help/faqs/security-and-compliance/postman-ai-resources) explica o que é enviado a modelos de terceiros.
- Revise sempre os testes gerados automaticamente: uma asserção que só verifica o status code, sem checar o corpo da resposta, passa mesmo quando a API está quebrada.
- Veja a [página oficial do produto](https://www.postman.com/product/agent-mode/) e o [webinar "Meet Agent Mode" (Postman Academy)](https://academy.postman.com/meet-agent-mode) para entender o que já está disponível e o que ainda está em evolução.

- [postmanlabs no GitHub](https://github.com/postmanlabs) — Organização oficial com o Newman, SDKs e demais projetos open source da Postman.
- [r/Postman](https://www.reddit.com/r/Postman/) — Subreddit da comunidade de usuários do Postman.
- [Postman Galaxy](https://www.postman.com/galaxy/) — Conferência anual e gratuita da Postman sobre o ecossistema de APIs.
- [Workspace API Evangelist na Postman](https://www.postman.com/api-evangelist/) — Coleções públicas mantidas por Kin Lane, referência histórica da comunidade de APIs.
- [TabNews](https://www.tabnews.com.br/) — Comunidade brasileira de conteúdo técnico, com discussões sobre back-end e APIs.
- [Desenvolvedores Brasil (Discord)](https://discord.com/invite/t3vYGUuK6P) — Comunidade brasileira com canais de dúvidas, vagas e mentorias.
- [DEV Community — tag Postman](https://dev.to/t/postman) — Artigos da comunidade sobre Postman, testes e automação de API.

## 🎓 Certificações

- [Postman Academy](https://academy.postman.com/) — Plataforma oficial de cursos e certificações da Postman.
- [API Testing Path (certificável)](https://academy.postman.com/path/api-testing-path-v12) — Trilha oficial e gratuita que emite badge de conclusão ao final.
- [FAQ da nova plataforma de badges](https://academy.postman.com/page/faq-new-badging-platform) — Explica como funcionam os badges/certificados emitidos pela Postman Academy.
- [Credly](https://info.credly.com/) — Plataforma usada para emitir e verificar badges digitais de certificações, incluindo as da Postman.
- [Parchment Badges](https://badges.parchment.com/) — Plataforma de emissão de badges usada pela Postman Academy para certificações mais recentes.
